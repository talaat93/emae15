# Photos de terrain — pages « métier + ville »

Déposez ici de **vraies** photos EMAE. Sans fichier, l'emplacement n'apparaît pas.

| Emplacement | Nom de base     | Où sur la page                                 | Quoi                            |
|-------------|-----------------|------------------------------------------------|---------------------------------|
| A           | `vehicule`      | après « Pourquoi EMAE à … »                    | véhicule floqué, secteur        |
| B           | `intervention`  | dans « Intervention en 3 étapes »              | technicien, équipement pro      |
| C           | `equipe`        | juste avant le formulaire de devis final       | équipe, chantier                |

Le site prend le fichier le plus précis qui existe :

1. `{emplacement}-{métier}-{ville}.webp` — ex. `vehicule-electricite-beaune.webp`
2. `{emplacement}-{métier}.webp` — ex. `intervention-plomberie.webp`
3. `{emplacement}.webp` — ex. `equipe.webp` (toutes les pages)

Métiers : `electricite`, `plomberie`, `chauffage`, `climatisation`.
Ville : le nom dans l'adresse de la page (`/intervention/beaune/...` → `beaune`).

Format conseillé : **1200 × 750 px (16/10), WebP, moins de 150 Ko**. `.jpg` est accepté aussi.
Pas de texte incrusté sur la photo. Évitez les plaques d'immatriculation et les visages de clients.
